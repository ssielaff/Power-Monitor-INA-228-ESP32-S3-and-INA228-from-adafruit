# Power-Monitor-INA-228-ESP32-S3-and-INA228-from-adafruit
Simple sketch for a power monitor using ESP32 S3 and INA228 from adafruit

I wanted a simple website that could display the volts, amps, and watts used by my DC power supply.  I was very lazy and just asked Google to lead me through the configuration and programming of the ESP32.

I used the ESP32 S3 because it has Wi-Fi, and enough memory to run a web server.  Meaning that once it’s configured, I just need to go to an IP address in my browser.  No other programs to install.

I used the following Products from Adafruit:

1 x Adafruit QT Py S3 with 2MB PSRAM WiFi Dev Board with STEMMA QT[ID:5700]
1 x STEMMA QT / Qwiic JST SH 4-Pin Cable - 50mm Long
1 x Adafruit INA228 - I2C 85V, 20-bit High or Low Side Power Monitor (STEMMA QT / Qwiic)
